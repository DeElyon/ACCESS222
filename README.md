# EL ACCESS CODING TUTORIAL 2.0

## 📌 Overview
EL ACCESS CODING TUTORIAL 2.0 is an interactive, responsive website designed for coding enthusiasts to **register, learn, and earn** through a structured tutorial program. It provides courses across different programming areas, including Python, JavaScript, HTML/CSS, and mobile development.

## 🚀 Features
- **Modern Navigation Bar** for seamless page transitions
- **Course Catalog** with detailed coding courses
- **Secure Payment System** (Bank transfer & automated receipt generation)
- **Referral Program** with earnings tracking
- **User Authentication & Unique ID Generation**
- **3D UI Effects** for an immersive user experience
- **Live Chat Support & FAQs**
- **Dark/Light Mode Toggle**

## 🖥️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** (Future updates may include Node.js or Firebase)
- **UI Design:** Open Sans Font, Blue & Ash White Theme
